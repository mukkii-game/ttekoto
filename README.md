# …ってコト⁉︎ — 量子力学おためし版

スマホ向け２択会話ゲーム。夕食選びと海の波のたとえから始め、二人の会話を通して二重スリット実験を学ぶ。12問を通して単一スリットの確率分布・確率振幅・位相・観察・経路情報・量子もつれ・デコヒーレンス・密度行列・量子消しゴム・遅延選択を扱う試作版。誤答時は短いヒントのあと同じ問題へ戻り、正解時は解説を読み終えてから画面をタップすると次の問題へ進む。

画面の文章は漢字かな交じりとし、手書き風で漢字までそろう Yomogi フォントを使用する。

## 起動

`python3 -m http.server 8080 --directory dist`

http://localhost:8080 を開く。依存パッケージ・ビルド不要。静的ホストには dist の内容を配置する。相対パス対応。

## 構成

- `dist/story.js`: 12問の問題文、選択肢、ヒント、解説。
- `dist/game.js`: 文字送り、正誤判定、再挑戦、仮の合成効果音。
- `dist/style.css`: スマホ用画面、二重スリット図、反応アニメーション。
- `dist/assets/`: ユーザー提供の仮画像、Yomogi フォントとその OFL ライセンス。音声の転載はなく、Web Audioによる仮の短音のみ。
