# …ってコト⁉︎ — 量子力学おためし版

スマホ向け２択会話ゲーム。左の子が右の子へ二重スリット実験を教え、10問を通して確率振幅・位相・観察・経路情報・エンタングルメント・デコヒーレンス・密度行列・量子消しゴム・遅延選択について学ぶ試作版。誤答時は短いヒントのあと同じ問題へ戻り、正解するまで先へ進まない。

画面に表示する文言は、ひらがなとカタカナを基本とし、意味のまとまりごとに空白を入れて読みやすさを補う。

## 起動

`python3 -m http.server 8080 --directory dist`

http://localhost:8080 を開く。依存パッケージ・ビルド不要。静的ホストには dist の内容を配置する。相対パス対応。

## 構成

- `dist/story.js`: 10問の問題文、選択肢、ヒント、解説。
- `dist/game.js`: 文字送り、正誤判定、再挑戦、仮の合成効果音。
- `dist/style.css`: スマホ用画面、二重スリット図、反応アニメーション。
- `dist/assets/`: ユーザー提供の仮画像と `chika-Regular.ttf`。音声の転載はなく、Web Audioによる仮の短音のみ。
