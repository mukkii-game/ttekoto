# …ってコト⁉︎ — pilot

スマホ向け２択会話ゲーム。４回の選択、16結末（真相ルート１本）。ユーザー提供の漫画画像を仮素材として使用する感触確認用パイロット。

画面に表示する文言は「ってコト⁉︎」の「コト」を除いてひらがなを基本とし、意味のまとまりごとに空白を入れて読みやすさを補う。

## 起動

`python3 -m http.server 8080 --directory dist`

http://localhost:8080 を開く。依存パッケージ・ビルド不要。静的ホストには dist の内容を配置する。相対パス対応。

## 構成

- `dist/story.js`: 分岐と結末。キーは選択履歴（0/1）。
- `dist/game.js`: 文字送り、分岐、仮の合成効果音、既読結末の端末保存。
- `dist/style.css`: スマホ用画面、反応アニメーション。
- `dist/assets/`: ユーザー提供の仮画像と `chika-Regular.ttf`。元画像をCSSで表示範囲指定。音声の転載はなく、Web Audioによる仮の短音のみ。

## 開発の次段階

表情差分・発声音声の差し替え、６〜７選択への拡張、シナリオの精査。現段階の表情は静止画で、喜び・戸惑い・恐れを動きと吹き出しで仮表現する。
